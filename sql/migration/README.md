# 增量脚本

上一次发布之后新增的结构变更放这里，文件名 `YYYYMMDD_简短说明.sql`。

已有环境（本地、远程、同事机器）执行这些脚本升级；新拉取项目的人不用管这里，
`../01_schema_and_init.sql` 已经包含了上次发布为止的全部结构。

发布后用 `../tools/rebuild_baseline.sh` 把这里的变更合并回基线，然后清空本目录。
完整说明见 `../README.md`。

要求：

- 可重复执行 —— 同一个脚本在三个环境上都要跑，跑两遍不能出错；
- 开头写清楚改了什么、为什么这么改；
- 动到月表的，同时改 `MonthlyTableInitializer` 的 `build*DDL`，否则下个月新建的表会缺列。
