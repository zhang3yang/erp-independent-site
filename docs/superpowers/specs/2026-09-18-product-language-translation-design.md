# 商品多语言机器翻译设计

## 目标

在独立站管理台的商品编辑弹窗中，为商品语言文案增加两种机器翻译入口：

1. 当前语言翻译：把站点默认语言的商品文案翻译到当前选中的语言。
2. 全部语言翻译：把站点默认语言的商品文案翻译到所有已开启且非默认的语言。

翻译结果只回填当前编辑表单，用户检查后点击“保存”才写入数据库。

## 范围

翻译字段包括：

- 商品标题
- 一句话卖点
- 商品详情 HTML
- SEO 关键词
- 规格型号名称

不翻译价格、图片、库存、状态、商品编码、分类等共享字段。

## 交互设计

语言页签区域增加：

- “当前语言翻译”按钮
- “全部语言翻译”按钮

默认语言页签不显示或禁用翻译按钮，因为它是翻译源语言。

当前语言翻译只处理当前目标语言；全部语言翻译处理站点已开启语言中除默认语言外的语言。

已有人工作译文不覆盖：

- 当前语言翻译只请求目标语言中为空的字段。
- 全部语言翻译只请求各目标语言中为空的字段。
- 如果目标语言字段全部已有内容，则提示无需翻译。

翻译按钮应显示加载状态，防止重复点击。完成后提示“机器翻译仅供初稿，请人工检查”，并保持编辑弹窗打开。

## 数据流

前端复用现有 `POST /site/translate` 接口，不在商品接口中保存翻译结果：

```text
默认语言表单内容
        ↓
筛选目标语言的空白字段
        ↓
POST /site/translate { from, to, texts }
        ↓
按固定下标回填目标语言表单
        ↓
用户检查/修改
        ↓
商品保存接口写入 u_s_sitegoods_lang / u_s_sitegoods_combo_lang
```

每次请求使用批量文本，并保持请求与响应下标一一对应。全部语言翻译按目标语言分别调用接口，单个语言失败时保留该语言原内容并继续处理其他语言，最后汇总失败语言。

## 后端复用与安全

现有翻译接口已经具备：

- `site:station:edit` 权限控制
- 支持语言白名单
- 批量数量和字符数限制
- 腾讯云密钥复用对象存储配置，不在前端暴露密钥
- 翻译错误码转为用户可理解的提示

本功能不新增密钥、不把翻译接口暴露给独立站访客，也不绕过商品保存接口的富文本白名单清洗。

## 覆盖与异常规则

- 默认语言为空的字段不发送，保持为空。
- 目标语言已有内容的字段不发送，保持人工译文。
- 源语言和目标语言相同不允许调用。
- 目标语言未在站点语言配置中开启时不处理。
- 翻译接口失败不清空已有数据。
- 详情字段翻译后仍由后端 `RichTextCleaner` 在保存时清洗。
- 用户关闭弹窗或取消保存时，机器翻译结果不落库。

## 测试验收

至少验证：

1. 当前语言翻译只改变当前语言的空字段。
2. 全部语言翻译会处理所有开启语言，但不覆盖已有译文。
3. 默认语言不会被改写。
4. 规格型号名称可以按语言回填。
5. 已有 HTML 标签翻译后仍能正常保存和展示。
6. 某一语言翻译失败时，其他语言仍可继续，错误提示包含失败语言。
7. 未配置翻译密钥、语言不支持、重复点击时有明确提示。
8. 保存后商品详情页对应语言显示新文案，刷新后仍存在。
