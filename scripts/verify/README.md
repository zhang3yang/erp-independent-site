# scripts/verify —— 装修内容那套逻辑的自动化校验

```bash
bash scripts/verify/run-all.sh
```

发版前跑一遍，几秒钟。四项全过才发。

## 为什么这几项单独拎出来

装修内容的合并那段代码（`SiteOpenService#siteContent` + `overlay`）**影响每个站点的
每个页面**——公司名、导航、Banner、页脚电话全经过它。而 `station-console` 里
没有测试框架（没有 `src/test`，`mvn` 也没配 surefire）。

在「不为这一处引入整套测试框架」的前提下，这四项是能自动化的那部分。

## 四项分别是什么

### 1. `check-merge-copy.js` —— 防漂移

`MergeCheck.java` 里那份 `overlay`、以及 `compose` 那一组，是从 `SiteOpenService.java`
**逐字拷**过来的（因为真代码在 Spring 容器里，单跑要拉起整个应用）。拷贝会过期，
过期之后真值表测的就不是线上那份逻辑了，而且**它照样全绿**——
这是这类「影子实现」最典型的失效方式。

所以真值表跑之前先比一遍：两边不一致就直接失败，不给你一个虚假的绿灯。
比的是**去掉注释之后的代码**，所以那几大段 javadoc 不用在真值表那边再抄一遍。

### 2. `MergeCheck.java` —— 三层合并 + 拼接的真值表

覆盖：

- v1（没有 `i18n` 键的老数据）原样返回；
- v2（只有 logo 能共享）照常；
- v3 共享层和语言层**同名对象合一层**（共享放电话、语言放地址，合出来四项都在）；
- **某语言只译了一半时按项退回默认语言**——这条是 2026-09-10 那次改动的重点；
- 数组是**整份替换**不按下标拼；
- 合并**不污染**共享层那份对象（同一次请求里连着取两种语言会踩）；
- `v` / `i18n` 这两个结构键不出现在接口返回里；
- 默认语言就是当前语言时不重复铺；
- **v4：共享的条目 + 语言层的文案按 id 拼**（导航、特色、能力、幻灯片、数字亮点、
  粉色数字卡），拼完文案袋子不许出现在接口返回里；
- v4 的**按条回退**：这一条没译就用默认语言那一条，而条数、网址、图标、数值
  三种语言完全一样；
- v3 那种「整条在语言层、没有 id」的条目**原样放行**（这是 v4 不需要迁移脚本的原因）。

单文件源码直接跑，不依赖项目的 classpath：`java scripts/verify/MergeCheck.java`。

> 控制台可能是乱码——Windows 默认代码页的问题，不影响判定。
> 看最后一行是「全部通过」还是「有 N 条不通过」，退出码也一致。

### 2b. `decorate-roundtrip.mjs` —— 管理台那张表单的「载入 → 保存」往返

上面两项管的是**读**那一侧（库里那份 JSON → 前台看到什么），这一项管**写**：
`DecorateForm.vue` 把老数据载进来、商家点一次保存之后，库里那份变成什么。

它把那个 `.vue` 的 `<script setup>` 抠出来、把 vue 之外的依赖换成空壳，在 Node 里
直接跑——所以跑的是**真代码**，不是第三份影子实现，也就不需要防漂移。覆盖：

- v2 / v3 老数据升上来：结构（条数、网址、图标、数值、图片）进共享层，
  各语言的文案按下标对进新袋子；条数按**最长的那种语言**算，少译的语言不该决定条数；
- 存出去是新结构：共享层一个文案都没有，语言层一个数组都没有；
- **再载一次不变形**（第二次保存和第一次逐字节一样）；
- 切语言时共享层一个字节都不动；
- 加一条、删一条是**所有语言一起**的，删掉时各语言的文案一并清掉；
- 一条都没配时整个键不写（写成 `nav: []` 会把后端的内置导航盖没）。

⚠ **模板里的绑定它验不到**——「格子绑错字段」那一类（2026-09-11 撞到过两次）
只能靠点开页面，或者对着 `shared` / `emptyLangForm` 把模板里的 `form.x` / `shared.x`
数一遍（`awk '/^<template>/,/^<\/template>/' | grep -o 'form\.[a-zA-Z0-9_.]*'`）。

### 3. `check-init-json.js` —— 新站初始内容那段 JSON

`sql/station/03_init_decorate.sql` 里那条 `UPDATE` 的值是**一整行几万字符**的 JSON
字面量（七种语言）。肉眼看不出括号漏没漏，而坏了要到新站首页上才发现。

这个脚本按 MySQL 的转义规则还原一遍再 `JSON.parse`，顺带查：
版本号、语言数、地图坐标有没有越界（经纬度填反是最常见的一种）、
`\n` 有没有被正确还原成真换行（`NO_BACKSLASH_ESCAPES` 那个坑）。
